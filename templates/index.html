Each model contributes its confidence the file is defective (or 100 − confidence if it voted clean). Weights reflect model accuracy.

Final verdict = majority vote: 3 or more of 5 models saying defective → "At Risk". A file can score 45% risk but still be flagged if 3 models agreed.

Individual metric baselines
Lines of Code size
Non-blank, non-comment executable lines. More lines = larger surface area for bugs, but size alone is not a defect signal.
≤ 200 · Small200–500 · Medium> 500 · Large, consider splitting
Cyclomatic Complexity key signal
Counts decision points: if, for, while, catch, and, or. How many paths can execution take? High = harder to test, more hidden bugs. 3rd most important (16.43%).
1–10 · Simple10–20 · Moderate, add tests> 20 · Complex, refactor
Functions structure
Total function/method definitions. Not bad alone, but combines with avg length and coupling to signal design problems.
1–15 · Normal15–40 · Large file> 40 · God file, split it
Classes structure
Class definitions in this file — not imported ones. Zero is normal for utility modules. Java/C# also count interfaces, enums, structs. Go counts structs. Rust counts traits.
0–5 · Normal5–15 · Large> 15 · Consider splitting
Comment Density readability
comment_lines ÷ total_lines. Too low = undocumented; too high = auto-generated or over-commented.
0.10–0.30 · Well documented0.03–0.10 · Sparse< 0.03 · Undocumented
Static Warnings key signal
Risky patterns: eval(, exec(, TODO, FIXME, HACK, os.system, catch(Exception), bare pass, etc. 2nd most important (23.93%). Even one FIXME increments this.
0 · Clean1–3 · Minor concerns> 3 · Needs review
Security Issues critical
Known dangerous patterns: eval(, pickle.loads(, yaml.load(, shell=True, verify=False, hashlib.md5(, innerHTML, dangerouslySetInnerHTML, and more. Even 1 warrants inspection.
0 · No known patterns1–2 · Review usage> 2 · Audit required
Duplication % maintainability
1 − (unique lines ÷ total lines). 0.30 = 30% of lines are duplicates of another line in this file. Bug fixes in one copy may miss others.
< 0.10 · Low0.10–0.30 · Moderate> 0.30 · Refactor into functions
Test Coverage Est. key signal
Language-specific patterns: Python finds def test_, class Test, assert, @pytest; Java finds @Test, assertEquals; JS finds describe(, it(, expect(. 4th most important (10.60%). Zero = no test keywords in this file — include your tests/ folder in the ZIP.
≥ 0.50 · Good test presence0.10–0.50 · Some tests< 0.10 · Likely untested
Coupling maintainability
Counts import, from, require, include, using statements. High coupling = tightly tied to many external dependencies, harder to test in isolation.
0–5 · Low5–15 · Moderate> 15 · Highly coupled
